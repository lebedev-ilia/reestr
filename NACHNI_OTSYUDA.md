## Два способа работы — выбери по своим возможностям

### Если ты можешь запускать код

Полный поиск. Ничего ставить не нужно: только Python из стандартной поставки
и SQLite. Ни зависимостей, ни служб снаружи, ни ключей.

```bash
python3 sluzhba/indeks.py                 # один раз после клонирования, ~1 мин
python3 sluzhba/nayti.py "что ищем"
python3 sluzhba/nayti.py "цена" --razdel resheniya --s 2026-09-01
python3 sluzhba/nayti.py --pokazat <источник> --metka <uuid>
```

Поиск отдаёт короткие выдержки и указатели, а не документы целиком — это
сделано под ограниченный контекст. Порядок такой: сначала поиск, он дёшев,
потом чтение **одного** нужного источника по указателю.

**Никогда не читай сырое целиком** — там более 18 000 ходов бесед
и больше тысячи файлов памяти систем.

### Если запускать код нельзя

Веб-нейросеть, песочница только на чтение — работай по заранее собранным
файлам:

1. `ukazatel/svodka.md` — последнее состояние.
2. `ukazatel/karta.md` — что есть и за какой период.
3. `ukazatel/hronika/<год-месяц>.md` — пересказ бесед по дням, читается подряд.
4. `zapisi/**/*.md` — осмысленные записи, их немного и они короткие.

Дословные беседы лежат в `syroe/besedy/` — это JSON построчно, каждая строка
один ход: кто, когда, текст. Открывай их **только** когда пересказа не хватает
и ты знаешь нужный день.

## Устройство

    NACHNI_OTSYUDA.md   этот файл
    USTAV.md            правила записи и поиска

    syroe/              свидетельство — только дописывается, не правится
      besedy/             дословные беседы по месяцам
      fayly/              файлы из бесед, по отпечатку содержимого
      sistemy/            память систем агентов (jarvis-3 и далее)

    zapisi/             осмысленное — правится и устаревает
      lyudi/ klienty/ proekty/ uroki/ fakty/ resheniya/ zhizn/

    sluzhba/            приём, сбор файлов, указатель, поиск, пересказ
    ukazatel/           производное: карта, сводка, пересказ, база поиска

**Два слоя нельзя путать.** `syroe/` — что было сказано и сделано, дословно.
`zapisi/` — выводы из этого. Каждая запись обязана указывать на сырое,
из которого выросла: **вывод без указателя на свидетельство — это мнение.**

## Чего здесь нет намеренно

**Базы поиска нет в хранилище.** `ukazatel/reestr.db` весит около 60 МБ
и полностью выводится из сырого — держать её в git значит носить с собой
то, что строится за минуту. Собери сам: `python3 sluzhba/indeks.py`.

**Осмысленный слой не наполняется машинально.** Когда принимали память
третьей системы — 1178 файлов, — их можно было разложить по разделам
скриптом. Этого не сделали: у записи обязаны быть срок годности и указатель
на источник, а проставленные автоматически они превращают осмысленный слой
в свалку с видом порядка. В `zapisi/` попадает только то, что кто-то
осмыслил и подписал. Если ты пополняешь реестр — держись этого.

**Паролей, ключей и доступов здесь нет и быть не должно.** На входе стоит
проверка содержимого, но это последний рубеж, а не разрешение.

## Если ты продолжаешь работу, а не просто читаешь

1. **Сначала ищи, потом говори «не помню».** Почти всё уже обсуждалось.
2. **Проверяй срок годности.** Цены, ставки и состояния проектов устаревают;
   запись без `godnost` через год врёт так же уверенно, как год назад
   говорила правду.
3. **Новые выводы записывай** в `zapisi/` по уставу — с шапкой, источником
   и сроком годности.
4. **Сырое не правь никогда.** Ошибся — добавь новую запись, а не переписывай
   свидетельство.

## Как реестр пополняется сам

На машине Ильи стоит крючок `Stop` в настройках Claude Code: после каждого
ответа агента запускается `sluzhba/obnovit.sh`. Она принимает новые беседы,
собирает упомянутые в них файлы, перестраивает указатель, пересобирает
пересказ, закрепляет изменения и раз в полчаса отправляет их в закрытое
хранилище.

Память агента в этой цепочке не участвует намеренно: забыть нечего, потому
что помнить не требуется.

Перенос на другую машину: склонировать, при желании поставить такой же
крючок, дальше всё то же самое. Приём заточен под расшифровки Claude Code;
память любой другой системы кладётся через
`sluzhba/prinyat_sistemu.py <путь> --imya <как назвать>`.
