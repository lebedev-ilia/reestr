# Реестр

Общее хранилище знаний: переписки, уроки, решения, факты, люди, клиенты.

**Смысл не в содержимом, а в том, что через год написанное сегодня можно
найти.** Поэтому здесь важнее всего три вещи: как пишется, как хранится
и как ищется.

Реестр переживает системы агентов. Система пересоздавалась трижды — реестр
один. Ничего внешнего: файлы, SQLite и Python из стандартной поставки.

## Быстро

```bash
python3 sluzhba/nayti.py "что ищем"        # выдержки и указатели
python3 sluzhba/nayti.py --pokazat <файл> --metka <uuid>   # один ход целиком
bash sluzhba/obnovit.sh                     # принять новое, перестроить указатель
```

Обычно обновлять руками не нужно: крючок `Stop` в Claude Code запускает
обновление после каждого ответа.

## Что служба делает сама

Принимает расшифровки Claude Code, затирает на входе ключи и куки, отбрасывает
повторы (при продолжении сессии история копируется в новый файл — без отбора
три четверти указателя были бы дублями), строит полнотекстовый поиск.
