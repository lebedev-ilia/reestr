# Посредники доступа к западным LLM API из России

Дата проверки: 27.08.2026. Все данные — с открытых страниц сервисов и открытых обзоров, без регистрации и оплаты.

Оговорка по методу: часть страниц с таблицами цен рендерится динамически (JS), автоматическое извлечение текста иногда даёт странные названия моделей (например «gpt-5.6-luna», «claude-fable-5» на странице цен ProxyAPI) — это не подтверждённые реальные названия моделей Anthropic/OpenAI, похоже на ошибку извлечения текста с динамической страницы. Такие цифры в файл не включены, вместо них — «не найдено / требует ручной проверки цен на сайте».

## ProxyAPI (proxyapi.ru)

1. владелец: ИП Баринбойм А.Н. — российский индивидуальный предприниматель (не ООО) ([apiportal.ru](https://apiportal.ru/catalog/proxyapi/)). Год начала работы не найден; независимый обзор пишет «стабильность подтверждена историей с 2023 года», но первоисточник этой даты не указан ([sostav.ru](https://www.sostav.ru/blogs/289807/86785)).
2. модели: OpenAI, DeepSeek, Gemini, Anthropic Claude заявлены на главной странице ([proxyapi.ru](https://proxyapi.ru/)); версии Claude на странице цен извлечь надёжно не удалось (см. оговорку выше). Есть отдельная документация по Anthropic (генерация текста, Batch API, prompt caching, vision, web search) ([proxyapi.ru/docs](https://proxyapi.ru/docs)). Поддержка OpenAI-совместимого формата подтверждена явно: «методы и параметры останутся такими же, как у оригинального API, можно использовать официальные библиотеки» ([proxyapi.ru](https://proxyapi.ru/)); есть отдельный раздел «Нативные API» и документация Anthropic — похоже на нативный Anthropic Messages API, но отдельный факт «это именно anthropic-совместимый endpoint» текстом страницы не подтверждён явно ([proxyapi.ru/docs](https://proxyapi.ru/docs)).
3. наценка: по независимому обзору (не с сайта ProxyAPI) — наценка «5-6 раз выше прямых тарифов» на флагманские модели, для Claude Sonnet названа цифра 774₽ вход / 3866₽ вывод за млн токенов ([sostav.ru](https://www.sostav.ru/blogs/289807/86785)). Другой независимый обзор даёт диапазон наценки от +140,1% до +628,4% в зависимости от модели ([neyronav.ru](https://neyronav.ru/providers/proxyapi)). Прямых цифр наценки на самом сайте ProxyAPI не найдено, официальная позиция сайта — «платите только за то, что использовали, без подписок и скрытых платежей» ([proxyapi.ru/pricing](https://proxyapi.ru/pricing)). Абонплата: не найдена. Минимальный платёж: не найден.
4. оплата и документы: «оплачивайте за потребляемые услуги в рублях с карты любого российского банка», для юрлиц — «оплата на расчётный счёт», заявлены «закрывающие документы» и «электронный документооборот» ([proxyapi.ru](https://proxyapi.ru/)); какие именно документы (акт/УПД/счёт-фактура) — не детализировано на просмотренных страницах.
5. ограничения: streaming подтверждён независимым обзором ([neyronav.ru](https://neyronav.ru/providers/proxyapi)); function calling, vision, длинный контекст для Claude — не найдено достоверно (на сайте есть раздел Anthropic vision, но без деталей) ([proxyapi.ru/docs](https://proxyapi.ru/docs)); лимиты запросов — не найдено.
6. риски: сайт заявляет работу «без VPN и блокировок» ([proxyapi.ru](https://proxyapi.ru/)); независимых свидетельств о случаях отключения ProxyAPI не найдено; отзывов на просмотренных страницах агрегаторов нет («опубликованных отзывов пока нет») ([neyronav.ru](https://neyronav.ru/providers/proxyapi)); данные о месте физического размещения серверов и трансграничной передаче персональных данных — не найдены.
7. соответствие правилам провайдеров: на сайте ProxyAPI явных заявлений о соответствии Usage Policy OpenAI/Anthropic не найдено. Общий разбор темы (не по ProxyAPI конкретно) утверждает, что схема «клиент → российский резидент-посредник → провайдер» не считается обходом гео-ограничений с точки зрения провайдера, так как для него это обычный трафик легального юрлица в поддерживаемой стране ([vc.ru/provod](https://vc.ru/provod/2959138-legalnost-ispolzovaniya-openai-i-claude-dlya-yurlic-v-rossii)).

Есть отдельная страница про 152-ФЗ и трансграничную передачу данных, но её содержание не прочитано (открывается отдельным документом) ([aitunnel.ru/legal](https://aitunnel.ru/legal)).

## GPTunneL (gptunnel.ru)

1. владелец: Shock Labs OÜ — частная компания, зарегистрирована в Эстонии 16.03.2016, рег. номер 14015152, юр. адрес Tallinna mnt 29-75, 20303 Narva, Эстония ([gptunnel.ru/en/documents/contract](https://www.gptunnel.ru/en/documents/contract)) — то есть иностранное (эстонское) юрлицо, не российское. По независимому обзору у сервиса свыше 1,5 млн зарегистрированных пользователей в 44 странах и «тысячи бизнес-аккаунтов» ([sborka.ai](https://sborka.ai/products/gptunnel)).
2. модели: заявлены ChatGPT, Claude, Gemini, Midjourney и «200+ моделей» ([gptunnel.ru](https://www.gptunnel.ru/en)); при этом пользователи сообщают, что часть заявленных моделей, включая Anthropic Claude и Perplexity Sonar, на практике недоступна ([отзыв, пересказанный по поисковой выдаче без прямой ссылки на источник отзыва — требует проверки]). OpenAI-совместимый формат подтверждён явно: «замените base_url на https://gptunnel.ru/v1 и ключ, остальной код без изменений» ([gptunnel.ru/en/docs](https://www.gptunnel.ru/en/docs)). Anthropic-совместимый формат — не найдено.
3. наценка: пользовательские отзывы называют «наценку 50%», при том что компания заявляет минимальные наценки ради стабильности сервиса (источник — агрегированный пересказ отзывов по поисковой выдаче, прямая ссылка на исходный отзыв не открывалась). Независимый ценовой разбор (блог BotHub, аффилированный источник) называет цену GPTunnel 5069₽ за млн токенов при заявленной сайтом цене 2700₽, предполагая «неточности встроенного токенизатора либо скрытые наценки» ([habr.com/companies/bothub](https://habr.com/ru/companies/bothub/articles/887772/)) — источник аффилирован с конкурентом, поэтому это утверждение конкурента о GPTunneL, а не независимая проверка.
4. оплата и документы: пополнение российскими способами оплаты, для корпоративных клиентов — постоплата или предоплата, оплата по счёту или корпоративной картой ([gptunnel.ru/en](https://www.gptunnel.ru/en)). В договоре-оферте (Shock Labs OÜ) закрывающие документы для российского юрлица (акт/УПД/счёт-фактура от резидента РФ) не упомянуты — оферта иностранной компании обычно не даёт права на вычет НДС и акт по российским правилам; прямого подтверждения ни в одну, ни в другую сторону не найдено, требует уточнения у самого сервиса.
5. ограничения: пользователи жалуются на скудную документацию API (не описаны все параметры), отсутствие streaming для части моделей и отсутствие переключателя «режима размышления» (агрегированный пересказ отзывов по поисковой выдаче).
6. риски: компания правомочна заблокировать доступ клиенту при нарушении условий, нехватке средств, chargeback, подозрении на мошенничество, нарушении авторских прав или непредоставлении запрошенных документов в течение 5 рабочих дней ([gptunnel.ru/en/documents/contract](https://www.gptunnel.ru/en/documents/contract)); бизнес-аккаунт не даёт автоматически отсрочку платежа или кредит ([gptunnel.ru/en/documents/contract](https://www.gptunnel.ru/en/documents/contract)). Про 152-ФЗ в договоре ничего не сказано — оферта ссылается на общую политику конфиденциальности без упоминания российского закона ([gptunnel.ru/en/documents/contract](https://www.gptunnel.ru/en/documents/contract)).
7. соответствие правилам провайдеров: договор требует от клиента «соблюдать условия и политики использования Поставщиков» и самостоятельно нести ответственность за модерацию запросов через API ([gptunnel.ru/en/documents/contract](https://www.gptunnel.ru/en/documents/contract)); явного заявления о статусе легального реселлера или о том, как именно соблюдается запрет на доступ из несанкционированных стран, не найдено.

## ЧЕГО НЕ УДАЛОСЬ ВЫЯСНИТЬ

- Год фактического начала работы (дата первого запуска сервиса, а не регистрации домена/юрлица) — у всех семи посредников, кроме VseGPT (косвенно, по обзору 2023 года) и NeuroAPI (косвенно, по номеру ОГРН).
- Точные версии моделей Claude, реально доступные прямо сейчас (не в маркетинговых текстах) — ни у одного посредника не удалось свести воедино непротиворечивый список: страницы одного и того же сайта называют разные версии в разных местах (см. «Противоречия»).
- Точная наценка к официальному прайсу провайдера, подтверждённая самим сервисом (а не сторонним обзором или конкурентом) — у ProxyAPI, AITunnel, GPTunneL, NeuroAPI, VseGPT.
- Официальный минимальный платёж и наличие/отсутствие абонплаты — у ProxyAPI, BotHub (кроме пакетных тарифов), NeuroAPI, VseGPT, provod.AI.
- Конкретный состав закрывающих документов (какие именно из договора/счёта/акта/УПД/счёт-фактуры выдаются) — у ProxyAPI (только общее «закрывающие документы»), BotHub (нужно запрашивать образец у самого сервиса — так и рекомендует независимый источник), GPTunneL (неясно, могут ли документы иностранной Shock Labs OÜ приниматься российской бухгалтерией), VseGPT (полностью не найдено), NeuroAPI (упомянута только оферта).
- Наличие/отсутствие function calling и потоковой выдачи (streaming) конкретно для Claude — у ProxyAPI, AITunnel, BotHub, VseGPT.
- Лимиты запросов (rate limits) — ни у одного из семи посредников не найдены явные цифры.
- Где физически расположены сервера обработки трафика и что заявлено про 152-ФЗ и трансграничную передачу персональных данных — подтверждено только для NeuroAPI (заявлена инфраструктура в России) и частично для AITunnel (есть отдельная неоткрытая страница про 152-ФЗ); у остальных пяти — не найдено.
- Официальная позиция каждого конкретного посредника по поводу правил Anthropic/OpenAI против перепродажи и доступа из несанкционированных стран — ни один посредник (кроме provod.AI, и то от собственного лица) не публикует явного разбора этого риска на своём сайте.
- Известные документированные случаи внезапного отключения клиентов конкретно у этих посредников (не в целом по рынку) — не найдено ни одного задокументированного случая ни по одному из семи сервисов на дату проверки.

## ПРОТИВОРЕЧИЯ

- **AITunnel, наличие Claude в продуктовой линейке.** Страница use-case по оплате в рублях перечисляет Claude как одну из доступных моделей ([aitunnel.ru/use-cases/ai-api-payment-rubles](https://aitunnel.ru/use-cases/ai-api-payment-rubles)), а страница про оплату для юрлиц того же домена вообще не упоминает Claude среди моделей, хотя заявляет «200+ моделей ИИ» ([aitunnel.ru/guide/kak-oplatit-openai-api-v-rossii](https://aitunnel.ru/guide/kak-oplatit-openai-api-v-rossii)).
- **AITunnel, минимальная сумма пополнения.** Независимый обзор называет минимальный депозит 399₽ ([sostav.ru](https://www.sostav.ru/blogs/289807/86785)), страница самого сайта — 500₽ ([aitunnel.ru/use-cases/ai-api-payment-rubles](https://aitunnel.ru/use-cases/ai-api-payment-rubles)).
- **GPTunneL, цена за млн токенов.** Компания заявляет одну цену (2700₽ по пересказу конкурента), конкурентный ценовой разбор (блог BotHub) насчитал 5069₽ за тот же объём и предположил либо ошибку встроенного токенизатора GPTunneL, либо скрытые наценки ([habr.com/companies/bothub](https://habr.com/ru/companies/bothub/articles/887772/)) — источник спора аффилирован с конкурентом BotHub, поэтому расхождение нельзя считать окончательно установленным фактом, а не элементом конкурентной борьбы.
- **BotHub, страна регистрации против позиционирования.** Реквизиты юрлица — казахстанское ТОО «БОТХАБ» ([bothub.chat/contacts](https://bothub.chat/contacts)), при этом в независимых обзорах и части собственных материалов сервис описывается как «российская платформа» без уточнения, что договор с клиентом заключает нероссийское юрлицо ([vc.ru/promptra](https://vc.ru/promptra/2959092-bothub-ili-prompta-chto-vybrat-dlya-biznesa)).
- **ProxyAPI, наценка.** Два независимых обзора дают разные оценки одной и той же величины: «5-6 раз выше прямых тарифов» на флагманы по одному источнику ([sostav.ru](https://www.sostav.ru/blogs/289807/86785)) против «+140,1%...+628,4% в зависимости от модели» по другому ([neyronav.ru](https://neyronav.ru/providers/proxyapi)) — по сути схожий порядок величины, но методика расчёта не совпадает и напрямую цифры не сверяются.
