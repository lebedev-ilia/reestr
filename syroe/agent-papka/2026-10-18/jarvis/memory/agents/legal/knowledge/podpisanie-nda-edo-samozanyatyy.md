## 1. Что реально у нас

Илья — самозанятый, ИП нет, ЭДО (Диадок/СБИС) не подключён. Госуслуги и Госключ
установлены, учётка подтверждена (сертификат в Госключе выпустился). Загранпаспорта
нового образца нет — УКЭП через Госключ недоступна, доступна только УНЭП.
Решение Ильи 31.08: основной способ подписания — УНЭП через Госключ, сканы —
запасной вариант, платные сервисы (Контур.Сайн) не заводим.

## 2. Правовая рамка

— Ст. 6 ч. 2 63-ФЗ «Об электронной подписи»: документ, подписанный НЭП/ПЭП,
  равнозначен подписанному собственноручно только при наличии соглашения
  сторон об этом (сверено ранее, 31.08.2026, в рамках job-163).
— Ст. 434, 438 ГК РФ: заключение договора обменом документами — сверено ранее
  вторичными источниками (не первоисточник).

## 3. Технический путь — ГЛАВНЫЙ ВЫВОД job-165

**Госключ НЕ подписывает произвольный файл, загруженный вручную (например, PDF,
присланный по почте).** Приложение принимает документ на подпись только через
интегрированный канал — от банка, госоргана, работодателя или через API стороннего
сервиса (в том числе ЭДО-оператора). Прямой кнопки «загрузить свой файл» в
Госключе нет.

Источник: вторичный — astral.ru/aj/elem/gosklyuch-na-praktike-oshibki-stsenarii-sboev-i-rabochie-resheniya/,
дословная цитата: «Подписание всегда инициируется внешним сервисом: банком,
оператором, ФНС, работодателем, контрагентом. Самостоятельно загрузить
произвольный файл из памяти телефона и подписать его в Госключе нельзя —
приложение работает только с документами, поступающими через защищённый канал.»
Первоисточник (официальная страница услуги на gosuslugi.ru/600373/1) через
WebFetch не отдал текст — портал вернул технический экран загрузки, не открывал
напрямую другим способом. Подтверждается косвенно и другими источниками
(bitrix24.ru, kontur.ru): везде описание идёт только через сценарий «сервис
отправил документ → Госключ получил уведомление».

**Что тогда остаётся, чтобы всё же подписать НАШ документ через Госключ:**
провести его через ЭДО-оператора, у которого есть встроенная интеграция с
Госключом. Подтверждено для Диадока: support.kontur.ru/diadoc/79739
(«Работа с Госключом — Диадок») — документ загружается в веб-версию Диадока,
оттуда кнопкой уходит в приложение Госключ на телефоне, там подписывается,
результат возвращается в Диадок. Также diadoc.ru/articles/86176 подтверждает,
что Диадок в принципе умеет принимать НЭП от физлиц/самозанятых без ИП и без
платы за это со стороны физлица (платит отправитех/организация за свою
отправку, входящие и подпись физлица бесплатны).

**НЕ ПРОВЕРЕНО ДО КОНЦА (кончился шаговый бюджет захода) — главный риск:**
описание интеграции «Диадок → Госключ», которое нашлось (support.kontur.ru/diadoc/79739),
по формулировке похоже на сценарий для сотрудника организации с КЭП физлица,
а не однозначно для самозанятого-одиночки без организации, подписывающего
именно НЭП. Не исключено, что связка «Диадок + НЭП + Госключ без организации»
работает иначе или недоступна вовсе. Единственный надёжный способ закрыть
вопрос — Илье самому один раз бесплатно завести аккаунт физлица в Диадоке и
посмотреть, предлагает ли интерфейс кнопку «подписать через Госключ» для НЭП.
СБИС в этом заходе отдельно не проверен вовсе (не хватило шагов) — считать
непроверенным.

## 4. Ответ, который я даю команде

**Можно при условии**, что документ проведён через ЭДО-оператора (Диадок или,
предположительно, СБИС) — прямая загрузка произвольного PDF в само приложение
Госключ технически невозможна. Условия:
1. Илья заводит бесплатный аккаунт физлица в Диадоке.
2. Загружает туда текст NDA.
3. Подписывает через встроенную кнопку «Госключ» (если она доступна для НЭП
   физлицу без организации — это и есть непроверенный пункт выше).
4. Скачивает подписанный файл + отсоединённую подпись (.sig/.p7s) и пересылает
   Николаю по почте, либо приглашает его как контрагента в тот же Диадок.

Если пункт 3 не сработает на практике (Диадок предложит только УКЭП или платный
тариф) — годный запасной вариант тот же, что и раньше: обмен сканами по почте
с оговоркой в тексте (уже есть, п. 7.3 нашей формы NDA), либо прямая НЭП без
Госключа непосредственно внутри Диадока (Диадок умеет выпускать свою НЭП для
физлиц отдельно от Госключа — это отдельная тема, здесь не поднималась).

## 5. Серьёзность

Если способ подписания в итоге останется «скан по почте» вместо Госключа —
ничего не грозит: п. 7.3 формы NDA уже даёт этому юридическую силу, устойчивость
соглашения определяется текстом (перечень КИ, потолок ответственности), а не
способом подписи. Цена ошибки здесь не денежная, а репутационная и по времени:
если пообещать Николаю Госключ, а на практике Диадок не даст подписать НЭП без
организации — придётся откатываться на сканы уже после того, как это назвали
основным способом.

## Что могло бы этот вывод опровергнуть

— Прямой заход в Диадок физлицом и практическая проверка, есть ли кнопка
  «подписать через Госключ» для НЭП без организации (самый быстрый и надёжный
  способ снять неопределённость — надёжнее любого дальнейшего поиска).
— Официальная документация Госуслуг/Минцифры по услуге 600373/1, которую не
  удалось получить через WebFetch в этом заходе (портал не отдал текст).
— Проверка того же вопроса по СБИС отдельно — не делалась вовсе.
