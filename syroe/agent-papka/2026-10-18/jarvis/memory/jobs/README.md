# memory/jobs — задания подагентам

По каталогу на задание: `job-NNN/brief.md` (что поручено), `job.json` (статус,
время, модель, стоимость, доставлен ли результат), `result.md` (что подагент
вернул). Пишет код — `core/jobs.py` и `modules/jobs/run.py`, руками здесь
ничего править не нужно.

Почему в памяти, а не в `derived/`: результат работы подагента не пересоздаётся
ничем. Снесу производную зону — вернуть его будет нечем, а это ровно то, что
запрещает правило `v-derived-tolko-vosstanovimoe`. В `derived/jobs/` остаётся
только сырой вывод процесса — он одноразовый.

Кто загоняет это под гит: шаг дневной свёртки `core/night.jobs_commit()` (bl-138,
30.08.2026). Он коммитит только завершённые задания — у идущего результат ещё
пишется. Пустой замок `job-NNN/.lock` в историю не идёт (`.gitignore`). Что зона
не расползлась вне гита, сторожит `core/selftest.test_jobs_tracked`: неотслеживаемый
след старше 26 часов — красное, и значит ночь не отработала.

Посмотреть журнал: `jarvis/.venv/bin/python -m jarvis.modules.jobs.cli list`
из каталога выше корня агента.
