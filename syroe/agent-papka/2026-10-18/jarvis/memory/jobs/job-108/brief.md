**Пункт 2. Шелл больше не обходит шлюз.** Сейчас в `core/agent.py` есть `SAFE_BASH`
(строка ~300) и ветка `if SAFE_BASH.match(cmd): return "allow", "чтение через шелл"`
(строка ~2218). `SAFE_BASH` смотрит только на ПЕРВОЕ слово команды, поэтому
`echo x > /etc/hosts`, `cat a.txt > ~/.bashrc`, `find / -delete`,
`python3 -c "import shutil; shutil.rmtree('/')"`, `echo x | tee /etc/passwd`,
`touch /tmp/x && cp secret /tmp/`, `bash -c "echo x > ~/y"` проходят как «чтение».
Требование Ильи дословно: команда считается чтением, ТОЛЬКО если в ней нет
`>`, `>>`, `|`, `&&`, `;`, обратных кавычек и `$(`; `python3 -c` и `bash -c`
из безопасных убраны совсем — для главного агента так же, как уже сделано для
ролей с зоной (см. ветку зоны, строки ~1610-1660 и ~1868 в core/agent.py).
