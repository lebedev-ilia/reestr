# Что можно самому

- Чинить `jarvis/modules/projects/*.py` (branches.py, cli.py и соседние) —
  эти файлы твои.
- Заводить пробную задачу протокола в проекте-полигоне `vnutrennii`
  (id возьми свободный, например t-004, имя — «проба веток»), заводить ветку,
  делать в ней коммиты, сливать её командой branch-merge, удалять свою ветку
  после слияния.
- Писать в `jarvis/derived/**` что угодно.
- Дописывать машинные проверки в самотест МОДУЛЯ (`jarvis/modules/projects/`),
  если там есть свой selftest.
- Коммитить ТОЛЬКО свои файлы поимённо (`git add <путь>`), никогда `git add -A`
  и никогда `git commit -a`: рядом идёт чужая работа.
