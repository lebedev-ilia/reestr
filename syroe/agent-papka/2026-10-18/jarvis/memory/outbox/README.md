# Журнал отправленных писем

Здесь `sent.jsonl` — одна строка на каждое письмо: когда, какой карточке, на какой
адрес, с какой темой, ушло или ошибка. Дозапись, редактировать руками не надо.
Владелец — агент, пишет `modules/outbox/send.py`.

Лежит в `memory/`, а не в `derived/`, потому что восстановить это неоткуда:
из журнала отвечают на единственный вопрос, который нельзя угадать заново —
кому уже писали. Пустой журнал означает «никому», и рассылка пойдёт по второму
кругу.

Пилотные письма (`--pilot ADDR`, письмо уходит на ящик Ильи вместо контакта)
пишутся с `"to": ""` и `"pilot": true` — иначе проверка навсегда заблокировала бы
отправку настоящему адресату.
