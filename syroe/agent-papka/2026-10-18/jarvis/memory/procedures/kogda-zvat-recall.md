## Предусловия
Оглавление памяти уже просмотрено: если тема есть строкой в facts/procedures, правильный ход — Read этого файла, а не recall. recall — для длинного хвоста, которого в оглавлении нет: подробности внутри файлов, слова Ильи, решения из лога.

## Шаги
1. Сформулировать запрос ИМЕНАМИ, а не вопросом. Это главный шаг, всё остальное второстепенно.
   — 2-4 существительных и собственных имени: «заём Семён долг», «синтез речи Piper», «перезапуск демона», «список 60 контактов».
   — Выбросить всё вопросительное и служебное: «сколько», «как», «когда», «какой», «от», «в».
   — Глаголы заменять отглагольным существительным: не «перезапустить» → «перезапуск», не «отправить» → «отправка».
2. Вызвать recall(query, days=400). Меньший days ставить, только если точно нужен свежий след.
3. Смотреть первые три строки выдачи. Строка вида «[факт → Read memory/facts/X.md]» — это адрес: открыть файл Read целиком, ответ внутри него, а не в показанном огрызке.
4. Не нашлось — попробовать второй набор имён (синоним, другой корень, имя собственное вместо описания). Два промаха подряд означают, что этого в памяти нет: так и сказать, не выдумывать.

## Известные грабли
— ГЛАВНОЕ, замерено 25.08.2026 на 10 живых запросах: вопросом «как перезапустить демона ВК» нужный файл на 11-й позиции, теми же словами «перезапуск демона» — на первой. По всему набору: вопросами 5 попаданий в первую тройку из 10, именами — 10 из 10. Промах recall почти всегда означает плохую формулировку, а не отсутствие записи.
— Словоизменение сводится (падежи, числа), словообразование НЕТ: «голос» не находит «голосовые», «отправить» не находит «отправка». Пробовать оба корня.
— Выдача ниже 60% веса лучшего попадания отсекается: если в топе оказался мусор, полезное могло не показаться вовсе. Перезадать запрос точнее, а не листать хвост.
— Записи лога показываются огрызком в 400 знаков и по нему же ищутся (правка 25.08). Ответ по логу восстанавливать чтением файла лога за ту дату, а не по фрагменту.
— «пароль», «доступ», «список» — слова-паразиты памяти: встречаются везде и дают мусорную выдачу. Заменять на конкретику: имя сервиса, ящика, файла.
