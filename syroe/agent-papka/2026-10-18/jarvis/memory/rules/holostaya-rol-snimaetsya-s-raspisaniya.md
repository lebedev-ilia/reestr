**Правило:** Постоянная роль, отработавшая вхолостую несколько заходов подряд (нечего принимать, нечего ставить), снимается с расписания полностью — every_minutes: 0, — а не «разрежается до пары часов». Роль при этом остаётся живой: текст задачи в ROLE.yaml сохраняется, поднять её руками через modules/agents/cli.py можно в любой момент. Вернуть расписание — только с прямого согласия Ильи.
**Почему:** 02.09.2026 тимлид vnutrennii поднялся вхолостую семь раз подряд по 0,36$ за заход. Я предложил Илье разредить расписание до пары часов, он ответил: «Да, пусть пока вообще не поднимается». Разрежение лечит частоту, а не причину: пока работы нет, любой автоматический заход — чистый расход денег и ходов. Работа появится — роль поднимут под конкретную работу, а не по таймеру.
**Как применять:** В ROLE.yaml ставить every_minutes: 0 и над блоком писать комментарием, кто и когда отключил и почему. Ноль одновременно снимает роль с планировщика (schedule.due пропускает minutes <= 0) и со сторожа (watchdog._period_seconds даёт 0 — роль не наблюдается), поэтому ложной тревоги «роль умерла» не будет. Блок schedule целиком не комментировать: текст задачи в нём нужен для ручных заходов. После правки проверить schedule.due() и прогнать modules/agents/selftest.py и ./jarvis --selftest по коду возврата, затем отдельный коммит.
