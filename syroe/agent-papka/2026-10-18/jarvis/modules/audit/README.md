# Самоаудит. Владелец: агент.

Машинная сводка собственного следа за сутки из `memory/log/<дата>.jsonl`:
падения, петли фоновых ходов, отбитые шлюзом вызовы, задания подагентам,
ручные повторы. Только чтение лога; результат — в `derived/audit/<дата>.md`.
Запуск: `python3 -m modules.audit.daily [ГГГГ-ММ-ДД]`. Задача bl-067.
С 26.08 руками звать не надо: дневная свёртка ночного цикла собирает сводку за
каждый свёрнутый день сама и вставляет последнюю в свой промпт (`core/night.py`,
`audit_block`, bl-084). Точка записи одна — `daily.write(день)`.

`spend.py` — счётчик расхода за день и за период: ходы, шаги, минуты
отдельно по видам (ВК, фон, подагенты) и цена справочной колонкой.
`python3 -m modules.audit.spend [ОТ [ДО]]`, самопроверка на фикстуре —
`--check`. Результат в `derived/audit/spend-<от>[-<до>].md`. Задача bl-063.
