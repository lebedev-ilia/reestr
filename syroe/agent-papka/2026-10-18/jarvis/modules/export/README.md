# modules/export

Здесь живёт сборка досье «кто мы и что продаём» для передачи наружу — другой
нейросети, клиенту, партнёру. Владелец — главный агент.

- `manifest.json` — адреса кусков памяти (файл + якорь начала и конца). Текста
  здесь нет: единственный источник правды остаётся в memory/facts и memory/rules.
- `dossier.py` — сборщик. `--check` проверяет якоря, `--passport` печатает общую
  часть, `--topic` строит каркас досье с пустыми клиентскими разделами,
  `--audience client` выкидывает внутреннее и ловит стоп-слова, `--out` пишет
  файл (только в derived/).
- `selftest.py` — 7 проверок, в общем прогоне `./jarvis --selftest` под именем
  «СБОРКА ДОСЬЕ».

Порядок работы — процедура eksport-konteksta-naruzhu: общая часть машиной,
клиентская половина и дословная переписка — руками.

Готовые документы лежат в derived/exports/ и восстановимы: снести можно целиком.
