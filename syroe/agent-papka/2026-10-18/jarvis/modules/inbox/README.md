# modules/inbox — чтение входящих по рассылке

Зачем: письма ушли, а читать ответы было некому. Модуль смотрит ящик
orient_dv@mail.ru по IMAP и отвечает на один вопрос — кто откликнулся,
до кого письмо не дошло, кто молчит.

Владелец: агент. Добавлен 23.08.2026 (задача bl-001, обязательство ob-008).

```
python -m jarvis.modules.inbox.read              # за 3 дня, сводка
python -m jarvis.modules.inbox.read --days 7 --full   # с текстом ответов
```

Только чтение. Папки открываются `readonly=True`, тела тянутся `BODY.PEEK[]` —
ящик живой, Илья им пользуется, и прочитанность писем мы не трогаем. Ничего
не удаляется и не перемещается; отвечать модуль тоже не умеет и не должен.

Разбирает «Входящие» и «Спам» (у mail.ru папка называется `&BCEEPwQwBDw-`).
Каждое письмо попадает в одну из четырёх корзин: живой ответ, автоответ, отлуп,
мимо рассылки. Последняя — личная почта Ильи, в журнал она не пишется и
печатается только по `--full`, шапкой без текста.

Свой корреспондент опознаётся по адресу из `memory/outbox/sent.jsonl`, по домену
этого адреса и по теме нашего же письма (человек может ответить с личного ящика).
Отлуп — по адресу, найденному в теле возврата.

Результат дописывается в `memory/outbox/replies.jsonl`, ключ против дублей —
Message-ID. Повторный запуск безопасен.

Правила классификации проверяются на моках без сети — см. `read_test_note.md`.
