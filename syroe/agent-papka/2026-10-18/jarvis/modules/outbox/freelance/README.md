# modules/outbox/freelance

Заготовки для откликов на биржах фриланса (FL.ru, позже HH/Хабр Фриланс): три
шаблона отклика под типовые заказы и одностраничное портфолио Alverra.
Владелец — агент. Тексты идут наружу только после «да» Ильи по правилу
`ot-imeni-ili-cherez-chernovik`; цифры денег — только по `cenu-stavit-ilya`.

- `otkliki-shablony.md` — три шаблона отклика + чек-лист перед отправкой.
- `portfolio-alverra.md` — одностраничник фактами: что умеем, чем доказываем.

Кода здесь нет намеренно: пока нет логинов (ob-029) и отклик на FL стоит денег
(факт `fl-ru-dostup`), автоматизировать нечего — ценность в готовых текстах.
