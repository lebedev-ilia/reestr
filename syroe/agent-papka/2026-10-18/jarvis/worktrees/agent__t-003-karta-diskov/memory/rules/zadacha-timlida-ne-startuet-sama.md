**Правило:** Задача, заведённая тимлидом через tasks.create(), сама себя не выполняет: тимлид только ставит её и условно числит исполнителя, а живого исполнителя запускаю я — заданием через modules.jobs.cli submit. Пока задание не поставлено, задача висит в статусе created и выглядит занятой, хотя не делается никем. Увидел новую задачу в проекте — в том же ходе либо запусти по ней задание, либо явно запиши, почему не сейчас.
**Почему:** 30.08 тимлид в 12:26 завёл t-002 и написал в журнале, что запускать исполнителя — дело Jarvis. Я этого не сделал, задача три часа висела как «занятая sonnet-1», и заметил не я, а Илья вопросом «кто-то её выполняет?». Строка «исполнители_заняты» создаёт ложное ощущение работы там, где её нет.
**Как применять:** В каждом ходе, где смотрю состояние проектов, сверять два списка: задачи в статусе created и живые задания в jobs_status. Задача created без своего running-задания — дыра, закрывать постановкой задания по процедуре zapusk-podagenta-zadaniem. Доказательство работы — id задания в очереди, а не строка «исполнитель занят».
