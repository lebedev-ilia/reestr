# Приёмка этапа 0: критерии

Написано 30.08.2026 до завершения работ. Проверяет Claude, не Jarvis и не тимлид.
Каждый пункт проверяется машинно или прогоном, а не чтением отчёта.

Правило то же, что мы навязали самому Jarvis: критерии написаны заранее и не
меняются по ходу. Не прошло — переделка, а не переформулировка критерия.

---

## Блокеры (без них приёмки нет)

**1. Полный самотест зелёный.**
`./jarvis --selftest` завершается кодом 0. Ни одного «СЛОМАНО».

**2. Шелл больше не обходит шлюз.**
Ни одна из этих команд не должна проходить как «чтение через шелл»:

```
echo x > /etc/hosts
cat a.txt > ~/.bashrc
find / -delete
python3 -c "import shutil; shutil.rmtree('/')"
echo x | tee /etc/passwd
touch /tmp/x && cp secret /tmp/
bash -c "echo x > ~/y"
```

Требование к правке: команда считается чтением только если в ней нет `>`, `>>`,
`|`, `&&`, `;`, обратных кавычек и `$(`. `python3 -c` и `bash -c` из безопасных
убраны совсем — для главного агента так же, как уже сделано для ролей с зоной.

**3. Записи вне папки агента нет ни одним путём.**
Ни через `Write`/`Edit`, ни через шелл. `worktrees` переехали внутрь корня —
иначе работа в ветках возможна только через дыру из пункта 2.

**4. Изоляция по проекту держится.**
Роль проекта А не читает и не пишет `memory/projects/B/**` и `B/.env`.
Проверяется прогоном с подставной зоной, а не чтением кода.

**5. Красный самотест блокирует приёмку задачи.**
Тимлид не может поставить «Выполнено», пока проверки красные. Проверяется
попыткой принять задачу при искусственно сломанном самотесте.

## Обязательные, но не блокирующие

**6. Потолок 100 строк отбивает и создание, и правку.**
Живая проверка: `task.md` в 101 строку не заводится и не сохраняется.

**7. Сторож поднимает тимлида.**
Процесс тимлида убивается — он поднимается сам, факт виден в логе и в
ближайшей сводке. Второй подъём за час уходит сообщением Илье.

**8. Сводка собирается кодом.**
При недоступной модели `render_text()` всё равно выдаёт семь пунктов раздела 7.
Проверяется без сети.

**9. Расход по проекту считается.**
Ненулевые сутки и неделя по проекту `vnutrennii`, числа сходятся с журналом
заданий.

**10. Ветки и коммиты по разделу 14.**
Ветка `agent/<id>-<коротко>` заводится на задачу, слияние делает только тимлид,
id задачи есть в сообщении коммита.
