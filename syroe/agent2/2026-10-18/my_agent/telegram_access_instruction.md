# Как дать агенту доступ к перепискам Telegram — инструкция

Дата: 2026-10-09. Для Chatbox (Desktop, macOS).

## Главное
- **Bot API (BotFather-токен) НЕ подходит.** Бот видит только сообщения, адресованные ему;
  личную переписку и историю он читать не может.
- Чтобы читать личные переписки, нужен доступ к **аккаунту пользователя через MTProto**
  (api_id + api_hash) — либо готовый экспорт истории.

---

## Вариант A — ЭКСПОРТ истории (рекомендую: безопасно, read-only, без риска бана)

1. Telegram **Desktop** → открыть чат с Сергеем → меню «⋮» → **Export chat history**.
2. Формат: **JSON** (для машинной обработки) или HTML. Медиа можно снять галочкой, чтобы файл был лёгкий.
3. Сохранить результат (файл `result.json` + папка) в рабочую папку, напр.:
   `/Users/user/Desktop/Agent2/telegram/`
4. Сказать агенту — он читает файл напрямую. Ничего устанавливать не нужно.

Плюсы: без API-ключей, аккаунт не рискует, я читаю локально.
Минусы: снимок на момент экспорта, не «живой» поток.

---

## Вариант B — MCP-сервер с доступом к аккаунту (живой доступ)

Читает переписки в реальном времени, но работает как **userbot** — есть риск
ограничений/бана аккаунта при агрессивном использовании.

**1. Получить api_id/api_hash**
- Зайти на **https://my.telegram.org** → Log in (номер телефона + код).
- «API development tools» → создать приложение → получить **api_id** и **api_hash**.
- Это секреты: не публиковать.

**2. Выбрать MCP-сервер (Telethon/MTProto, читает личные чаты)**
- `github.com/chigwell/telegram-mcp` (Telethon: чтение чатов, поиск, медиа).
- `github.com/sparfenyuk/mcp-telegram` (MCP из Telegram CLI).
- `github.com/chaindead/telegram-mcp`.
Установка: обычно `uvx`/`pipx` или `pip install` + команда запуска.

**3. Подключить MCP в Chatbox**
- Chatbox → **Settings → MCP → Add Server** (STDIO или Streamable HTTP).
- Прописать команду запуска и переменные окружения:
  `TG_API_ID`, `TG_API_HASH` (и путь к session-файлу).

**4. Первая авторизация**
- При первом запуске сервер запросит **номер телефона + код из Telegram** → создаст session-файл.
- Дальше я смогу читать чаты через MCP-инструменты.

Минусы/риски: userbot = ваш аккаунт; возможен вход с нового устройства (уведомление/сессия);
спам-запросы → флуд-лимиты и бан. Только чтение, без массовых действий.
