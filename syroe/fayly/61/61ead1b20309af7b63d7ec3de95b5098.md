TrendFlow — ML SaaS для анализа YouTube-видео и предсказания просмотров/лайков через 7/14/21 дней.

**Структура:**
- MLService (уже реализован): Fetcher + DataProcessor (75+ компонентов) + Models (Transformer fusion)
- Backend: FastAPI + PostgreSQL + Celery + Redis + WebSocket — каркас реализован
- Сайт: Frontend — НЕ реализован, нужно построить с нуля

**Полное ТЗ:** `/Users/user/Desktop/TrendFlowML/docs/WEBSITE_REQUIREMENTS.md`

**Ключевые решения по сайту:**
- Frontend: Next.js 15 + TypeScript + Tailwind + Three.js/R3F + Recharts/Nivo + Zustand + TanStack Query
- Дизайн: тёмная тема (приоритет) + светлая, минималистичный+технологичный, фиолетовые акценты (#7c3aed)
- 3D: floating card на лендинге (React Three Fiber) с анимацией видео→прогноз→скор
- Биллинг: гибрид (план включает кредиты + докупка), ЮKassa первым, потом Stripe
- Invite-only: регистрация закрыта, admin создаёт пользователей
- Workspaces: командная работа (owner/admin/editor/viewer)
- Virality Score: число 0-100 с цветом (зел/жёлт/красн)
- Прогресс анализа: WebSocket + реальные кадры с YOLO bbox
- Язык: только русский (v1)
- Результаты хранятся 30 дней
- Публичный share: только скор + топ-3 рекомендации

**Фазы разработки:** MVP → Расширение → Полный продукт (детали в ТЗ)

**Why:** Проект личный, сроков нет, Claude пишет 90% кода.
**How to apply:** При работе над сайтом — всегда читать ТЗ и backend код перед реализацией.
