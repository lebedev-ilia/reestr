# Реестр

Хранилище, которое переживает системы агентов. Система пересоздавалась трижды,
реестр один. Полные правила — `/Users/user/Desktop/reestr/USTAV.md`.

## Сначала искать, потом говорить

Прежде чем ответить «не помню» или «мы, кажется, решали» — искать.
Вся переписка с Ильёй сохранена: расшифровки Claude Code принимаются
в реестр крючком автоматически.

```bash
cd /Users/user/Desktop/reestr
python3 sluzhba/nayti.py "прокси Владивосток"
python3 sluzhba/nayti.py "цена Kwork" --razdel besedy --s 2026-09-01
python3 sluzhba/nayti.py "Олег" --skolko 20 --shire
```

Выдача — короткие выдержки и указатели, не документы. Это сделано под
ограниченный контекст: сначала поиск, потом чтение одного нужного источника.

```bash
python3 sluzhba/nayti.py --pokazat syroe/besedy/2026-09/<файл>.jsonl.gz --metka <uuid>
```

**Никогда не читать сырое целиком** — там более восемнадцати тысяч ходов
бесед и 1178 файлов памяти систем.

Память систем агентов лежит в `syroe/sistemy/<имя>/`, разделы в поиске
имеют вид `jarvis-3/facts`, `jarvis-3/agents`, `jarvis-3/rules`:

```bash
python3 sluzhba/nayti.py "Николай" --razdel jarvis-3/drafts
python3 sluzhba/prinyat_sistemu.py <путь к memory> --imya jarvis-4   # новая система
```

## Записывать, когда появилось осмысленное

Переписка сохраняется сама. Руками пишутся только выводы: урок, решение,
проверенный факт, сведения о человеке или клиенте.

Куда: `zapisi/{lyudi,klienty,proekty,uroki,fakty,resheniya,zhizn}/`

Обязательная шапка — `imya`, `data`, `tip`, `istochnik`, `godnost`, `tegi`.
Поле `istochnik` указывает на сырое, из которого вырос вывод: **вывод без
указателя на свидетельство — это мнение.**

Поле `godnost` обязательно: цены, ставки и состояния проектов устаревают,
а запись без срока годности через год врёт так же уверенно, как год назад
говорила правду.

## Файлы

Присланные документы и созданные отчёты лежат в `syroe/fayly/` по отпечатку
содержимого, опись — `syroe/fayly/_opis.jsonl` (отпечаток, имя, откуда, когда).
Найти присланный когда-то файл:

```bash
grep -i "ТЗ_ML" syroe/fayly/_opis.jsonl
```

## Что происходит само

Крючок `Stop` в `~/.claude/settings.json` после каждого ответа запускает
`sluzhba/obnovit.sh`: новые беседы принимаются, упомянутые файлы собираются,
указатель перестраивается, секреты затираются. Команды и их результаты
сохраняются целиком, без обрезания. Помнить об этом не нужно — нужно этим пользоваться.

Если крючок вдруг снят или реестр отстал — `bash sluzhba/obnovit.sh`.

## Границы

В реестр не попадают пароли, ключи и доступы — никогда, даже в закрытое
хранилище. Затирание на входе есть, но это последний рубеж, а не разрешение.
