# 03 — Продажи, клиенты и сделки

Система одновременно тестирует:
FL.ru ;
Fiverr / Upwork;
Telegram и профессиональные сообщества;
холодный outreach;
агентства и студии как канал субподряда;
другие релевантные источники.
Каналы сравниваются по  чистой прибыли на час внимания , а не по размеру аудитории.
Агентный pipeline
Сбор → дедупликация → квалификация → анализ → P(win) → EV → отклик → проверка → отправка → follow-up → CRM → обучение модели.
Отклики
Фиксированного числа откликов нет.
Низкоценные возможности: максимально автоматизированный отклик, если риск низкий.
Средние: агент готовит, ты быстро проверяешь.
Высокие: глубокий анализ + обязательная ручная проверка.
Крупные сделки: ручное подтверждение.
Цель —  не количество отправленных сообщений, а стоимость привлечённого клиента и чистая прибыль .
Cold outreach
Агент:
находит компании;
квалифицирует их;
анализирует продукт/бизнес;
формулирует вероятную проблему;
готовит персонализированное предложение;
готовит follow-up.
Для ценных лидов отправка остаётся под твоим контролем.
Работа с клиентом
Неясное ТЗ
Не отбрасывать автоматически. Это может быть платная услуга:
discovery → варианты решения → scope → цена → пилот → основной проект.
Оплата
Схема зависит от суммы, риска, длительности и истории отношений.
Для новых или рискованных проектов предпочтительны  предоплата и/или этапы .
Отсрочка платежа учитывается как финансовый риск.
Scope
Собственные ошибки исправляются бесплатно.
Новые требования после согласованного scope — отдельная работа.
Для ценного клиента возможен ограниченный goodwill-компромисс, но не бесконечный scope creep.
Цена
Не демпинговать из-за AI.
Использовать уровни:
Базовый → Основной → Расширенный.
При ценовом возражении:
уменьшить scope → предложить варианты → торговаться только внутри минимально допустимой цены.
Retainer
Retainer предлагается не автоматически после первого проекта, а когда история показывает  реальную регулярную потребность .
CRM
После проекта:
результат → следующий шаг → follow-up → напоминание → повторная продажа.
Проигранные лиды не удаляются автоматически: сохраняем причину проигрыша и перспективных клиентов возвращаем в работу.
Клиентский риск
Отдельно оцениваются:
качество ТЗ;
склонность к правкам;
платежная дисциплина;
стоимость коммуникации;
вероятность scope creep;
концентрационный риск;
фактическая прибыльность после закрытия заказа.
«Высокий чек» не делает плохого клиента хорошим.
