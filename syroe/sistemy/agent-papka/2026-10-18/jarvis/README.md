# JARVIS

Личный агент Ильи. Растёт сам под реальные задачи.

Читать в этом порядке: `CONSTITUTION.md` — как он думает и действует. `MEMORY.md` — формат его памяти.
Оба файла меняет только Илья. Всё остальное агент ведёт сам.

## Запуск

Работает через подписку Claude (Max) — API-ключ не нужен. Agent SDK ходит
через локально установленный Claude Code, поэтому расход идёт по лимитам
подписки, как у `claude -p`.

```bash
npm install -g @anthropic-ai/claude-code    # если ещё нет
claude login                                # вход по подписке, один раз
./setup.sh                                  # venv + зависимости + проверка
```

Дальше всё через обёртку — venv активировать не нужно, она сама:

```bash
./jarvis                 # диалог
./jarvis "вопрос"        # один ход
./jarvis --night         # ночной цикл вручную
./jarvis --context       # что уходит в контекст (отладка)
```

## Разрешения

Решает один шлюз в `core/agent.py` по цене ошибки, а не по сложности действия.
Чтение, память и запись **в свою папку** проходят молча — всё под гитом, откатывается.
Запись за пределы папки запрещена всегда, в любом режиме. Разрушительные команды
(`rm -rf`, `sudo`, `git push`, `curl | sh`) запрещены навсегда, включая `yolo`.

```bash
./jarvis                                  # normal: молча работает у себя, спрашивает про внешний мир
JARVIS_PERMISSION=careful ./jarvis        # спрашивает про любой шелл, меняющий состояние
JARVIS_PERMISSION=yolo ./jarvis           # не спрашивает ничего, кроме запрещённого навсегда
```

В ночном цикле «спросить» автоматически становится «отказать»: подтверждать в
четыре утра некому, и агент записывает это предложением вместо действия.

## Ночной цикл

Расписание живёт внутри демона ВК (`core/night.py`): пока он работает, свёртки
запускаются сами. Крон не нужен — на домашней машине он промахивается мимо
выключенного компьютера, а здесь сравнивается не время, а «какой период уже
свёрнут» (`derived/night.json`), поэтому пропущенное догоняется при следующем
запуске.

* день закрывается в `JARVIS_NIGHT_HOUR` (по умолчанию 4 утра по `JARVIS_TZ`);
* неделя — после воскресенья, месяц — после последнего числа;
* несколько пропущенных дней сворачиваются одним ходом, а не пятью;
* период отмечается свёрнутым **до** хода: упавшая свёртка пропускается
  до следующего дня, чтобы дорогой ход не крутился по кругу.

```bash
./jarvis --night          # свернуть последний закрытый период прямо сейчас
./jarvis --night due      # только если пора (то же, что делает демон)
python -m jarvis.core.night          # что свёрнуто и что ждёт очереди
python -m jarvis.core.night_selftest # проверка расписания на моках
```

Канал связи пока один — терминал. ВК и всё остальное агент строит себе сам,
модулем в `modules/`. Это его первая настоящая задача, а не часть семени.

## Что где лежит

| Путь | Зона | Что |
|---|---|---|
| `CONSTITUTION.md` | исходное | семя: позиция, режимы работы, границы |
| `MEMORY.md` | исходное | схема памяти |
| `core/` | исходное | главный цикл и ядро |
| `modules/` | исходное | то, что агент написал себе сам |
| `memory/log/` | **неизменяемое** | поток событий, только дозапись |
| `memory/` (остальное) | исходное | факты, процедуры, правила, реестры |
| `derived/` | **производное** | индексы и свёртки, сносится и пересобирается |

Закон папки: всё, что можно пересоздать, лежит в `derived/` и удаляемо в любой момент.
Новые папки верхнего уровня не создаются. У каждой вложенной — свой README.
