## 1–2. Блоки системного промпта: байт, потолок, режется ли

Два столбца байт: «в промпте» — после ужатия своим потолком (то, что реально
уезжает в ход), «сырой» — до ужатия (то, во что блок вырос на самом деле).
«Режется» = сырой > потолка (кроме блока `log` — у него скользящее окно,
он упирается в потолок каждый день по устройству, это не авария).

| rollups (свёртки) | 6 937 | 6 937 | 11 000 | нет | — |

Рамка блоков (заголовки `# ...`) — 1 462 байт. Конституция — 16 313 байт.

**Сумма блоков «в промпте» (73 582) + конституция (16 313) + рамка (1 462) =
91 357 байт** — ровно совпадает с полем `current` из `context_budget()`
(91 357), расхождение 0%.

Худший случай (все блоки разом упёрлись в свои потолки): **109 275 байт**
(`worst`) при бюджете 120 000 байт (`budget`, = 30% окна модели 200k
токенов × 2 байта/токен) — 91% бюджета. В токенах: 45 678 из 60 000 сейчас
(76%), 54 637 из 60 000 в худшем случае (91%).

Уже режутся два блока не по устройству: `morning` (разбор сроков, обязательства
одного дня не влезают в 3 КБ) и `index` (оглавление памяти — это и есть больной
блок реформы, растёт ~1 КБ/сутки, потолок 18 КБ уже сегодня тесен на 2,3 КБ).

## Как повторить замер (снять «после» тем же способом)

Все команды — из каталога `/home/ilya/Рабочий стол/Agent/jarvis`, интерпретатор
`.venv/bin/python`, для импорта пакета `jarvis.*` нужен `PYTHONPATH=..`
(корень пакета — на уровень выше, `/home/ilya/Рабочий стол/Agent`).

```
cd "/home/ilya/Рабочий стол/Agent/jarvis"

# 1-2. Блоки промпта и потолки — сырой JSON
PYTHONPATH=.. .venv/bin/python -c "
import json
from jarvis.core import memory as M
print(json.dumps(M.context_budget(), ensure_ascii=False, indent=2))
"

# 3. Файлы и объём каталогов памяти
for d in memory/facts memory/procedures memory/rules; do
  n=$(ls "$d" | grep -c '\.md$'); sz=$(du -sb "$d" | cut -f1)
  echo "$d: файлов=$n байт=$sz"
done

# средняя длина строки оглавления
PYTHONPATH=.. .venv/bin/python -c "
from jarvis.core import memory as M
body = M._block_body('index')
lines = [l for l in body.split(chr(10)) if l.strip().startswith('- ')]
print(len(lines), sum(len(l.encode()) for l in lines)/len(lines))
"

# 4. Прирост файлов памяти за 7 суток
for d in facts procedures rules; do
  git log --since="7 days ago" --name-only --diff-filter=A --pretty=format: -- memory/$d \
    | sort -u | grep -c '\.md$'
done

# 5. Расход за сутки (подставить нужную дату)
cd "/home/ilya/Рабочий стол/Agent" && jarvis/.venv/bin/python -m jarvis.modules.audit.spend 2026-09-01
```

Оговорка про git-права: `mkdir`/`tee`/запись файлов через шлюз проходят
только когда рабочий каталог shell — сам `jarvis/`, а путь относительный
(`derived/...`). Из родительского `Agent/` те же относительные пути
`jarvis/derived/...` шлюз режет («запись вне папки агента запрещена»),
хотя путь физически внутри агента — известная грубость проверки текстом
команды, а не разрешённого пути. Обходной приём рабочий, чинить его не входило
в это задание.
