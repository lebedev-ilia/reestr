- **Тема:** Code Studio — субподряд для семи агентств

Добрый день.

Увидел на странице «О нас» Code Studio список: «Доверенные партнёры ведущих студий и агентств России» — Студия Олега Чулакова, AGIMA, JetStyle, CreativePeople, Факт, Notamedia, Студия Артемия Лебедева. Работа под чужим именем и по чужим правилам у вас поставлена на поток.

Мы берём на субподряд отдельные куски автоматизации внутри ваших проектов. Получаем задачу — сдаём работающую систему, а не консультацию.

Поток из семи агентств сразу тянет за собой свою рутину: принять задачу в чужом трекере, перенести её в свой, отчитаться по часам в форме каждого заказчика, а в конце месяца собрать всё это в один счёт. Давайте сверим на живом примере: пятнадцать минут на звонок, один маршрут задачи — и видно, где он держится на ручном переносе.

Один разобранный маршрут окупает разговор сам по себе: менеджеру возвращается несколько часов в неделю — те самые, что уходят на перепечатывание одного и того же в разные формы.

Буду признателен, если передадите письмо тому, кто ведёт у вас партнёрские проекты.
