# memory/drafts — черновики, ждущие «да» Ильи. Владелец: главный агент.

Здесь живут только тексты, которые уже показаны Илье по правилу
`ot-imeni-ili-cherez-chernovik` и ждут его слова: письма, отклики, сообщения от
его имени. Восстановить их нечем — правки Ильи и согласованная формулировка
существуют в одном экземпляре, поэтому derived им не место (bl-051).

Илья сказал «да» и текст ушёл — файл удаляется, след остаётся в журнале
отправленного (`memory/outbox/sent.jsonl`). Рабочие черновики ролей и мои
собственные наброски сюда не кладутся: им место в `derived/drafts/<роль>`.
