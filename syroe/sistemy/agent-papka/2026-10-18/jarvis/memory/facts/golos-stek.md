Собрано и проверено вживую 22.08.2026, модуль modules/voice/.

Синтез: Piper (piper-tts, ONNX, CPU), 5-11x реалтайма — шестисекундная фраза
за полсекунды, без интернета и оплаты. Русские голоса с huggingface.co/rhasspy/
piper-voices (~61 МБ), скачаны dmitri/denis/ruslan в derived/voices/ (вне гита).
По умолчанию ruslan — выбор Ильи 22.08 из трёх проб.

Вернуть голоса после сноса производной зоны: `python3 -m jarvis.modules.voice.fetch`
(один ruslan), `--all` (все три), `--check` (жива ли ссылка, не качая). Модуль
написан 26.08 по ревизии bl-051: до этого say.py обещал «скрипт ниже», а скрипта
не было — 181 МБ жили в derived без команды восстановления. Три голоса ссылками
проверены живыми 26.08, по 60 МБ каждый.

Кодирование в ogg/opus — через soundfile (libsndfile 1.2), системного ffmpeg
на машине НЕТ и без sudo не поставить. Обязателен ресемплинг через soxr: Opus
принимает только 8/12/16/24/48 кГц, а piper-medium отдаёт 22050 — без
ресемпла запись падает с LibsndfileError, а не тихо портится.

Отправка голосового от имени сообщества ВК работает (не очевидно, проверено):
docs.getMessagesUploadServer(type=audio_message, peer_id) -> multipart POST
полем "file" с именем file0.ogg -> docs.save -> messages.send с вложением
doc<owner_id>_<id>[_<access_key>]. Длительность и waveform ВК считает сам.

Своего голоса нет: Piper-голоса чужие, из набора. Клонирование (XTTS) на этом
железе — минуты на фразу, для диалога непригодно; клонированный голос
достижим только облаком (ElevenLabs и подобные) — деньги и текст наружу.

Свободное место в памяти не держать, смотреть `df -h /`. Настоящее и
устойчивое ограничение машины другое: CPU без пригодного для вычислений GPU
(mashina-doma).

Дом этого файла — нижние пороги озвучки: ответ прогоняется через
speakable.prepare, и если речи осталось меньше 30 знаков ИЛИ меньше 40%
исходного — уходит текстом (сами пороги в коде живут в modules/vk/daemon.py,
функция pick_mode, там же VOICE_LIMIT). Выбор канала по длине и метке — в
golos-ili-tekst. Грабля, на которой 23.08 полдня стоял красный самотест:
«Готово» и «ответ на: привет» штатно уходят текстом, это не поломка —
проверять живой длиной.
