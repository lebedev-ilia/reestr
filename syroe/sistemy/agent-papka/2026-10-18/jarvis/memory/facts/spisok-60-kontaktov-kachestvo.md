Проверено 22.08.2026 модулем jarvis/modules/outbox (contacts.py + checkdns.py).

Разобрано ровно 60 карточек, у всех есть черновик письма прямо в карточке —
пропусков нет. Отправляем не его, см. spisok-60-kontaktov.

Каналы по числам — в spisok-60-kontaktov, здесь только качество. Уникальных
доменов 54, дублей адресов нет. Карточки 3.1-3.4 машиной не отправить никак —
у них нет ни почты, ни телеграма, только форма на сайте или профиль vc.ru.

MX-проверка: все 54 домена живые, мёртвых адресов нет. То есть отлупов
по несуществующим доменам не будет — но существование конкретного ящика
DNS не подтверждает, это проверится только отправкой.

Главная слабость списка: 39 адресов из 54 — общие ящики (info@, hello@, hr@,
sales@, office@, mail@). Это не личная почта ЛПР, и ответа оттуда ждать
намного реже. Личных адресов меньше четверти списка.

Телеграм в списке почти весь не личный: два адреса — боты (@Daccel_agency_bot,
@purr_web_bot), один — публичный канал (@egoshin_kedprof), остальные корпоративные
аккаунты компаний и номера для приглашения. Личный аккаунт живого человека
в списке ровно один: @voroncovasofia, HR студии Qtim. То есть телеграм — канал
до компании, а не до ЛПР, и на «написал в тг — дошло до решающего» рассчитывать
нельзя.

Дыра в исходном файле: у писем нет темы (Subject) — поля «Тема» в карточках
нет вообще. Закрыто 22-23.08: темы вынесены в отдельный файл и живут вместе с
каркасами, см. pisma-shablony-i-otkliki. Из карточки тему брать неоткуда —
не искать.
