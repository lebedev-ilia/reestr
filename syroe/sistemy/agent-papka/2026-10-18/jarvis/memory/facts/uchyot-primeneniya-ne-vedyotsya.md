Из шести слоёв памяти счётчик применения есть только у способностей. У правил и процедур его нет либо он считает не то. Это ограничивает любую ревизию: пункты «неприменявшееся вычистить» по ним неисполнимы.

ПРАВИЛА. Схема MEMORY.md §6 задаёт шапку id, scope, created, source, status. Полей last_used и applications нет ни в схеме, ни фактически ни в одном из 57 файлов. При этом MEMORY.md §6 требует помечать retired правила, не применявшиеся 60 дней, — механизм неисполним, данных для него не существует нигде.

Чем можно мерить вместо этого: числом вхождений id правила в memory/log/*.jsonl. Команда — цикл по memory/rules/*.md с `grep -ohF "$id" memory/log/*.jsonl | wc -l`. Это мера КАСАНИЯ, не применения: id попадает в лог и когда правило создано, и когда просто прочитано. Годится, чтобы отличить живое от мёртвого, и не годится как основание для retired.

ПРОЦЕДУРЫ. Поля runs, failures, last_used в шапке есть, но их не обновляет ни одно место кода по факту применения. core/memory.py при перезаписи процедуры поднимает старые значения из шапки и ставит runs+1 — то есть runs считает ПЕРЕЗАПИСИ процедуры, а не запуски, а failures не растёт никогда и стоит нулём везде, кроме perezapusk-demona-vk (там 1 проставлена рукой). Критерий «три провала подряд» не сработает ни при каких обстоятельствах.

Признак, по которому это видно без чтения кода: last_used совпадает с created у 19 процедур из 25, а golosovoe-v-vk показывает runs 2 при 95 голосовых у cap-002 и zapusk-podagenta-zadaniem — runs 1 при 172 заданиях подагентам за август.

СПОСОБНОСТИ — единственный работающий учёт: core/registry.py, словарь LOG_RULES, пересчёт зовёт ночной цикл. Устройство и правила счёта — memory/registry.md, раздел «Как считаются числа». Если чинить учёт правил и процедур, чинить надо по этому образцу: счёт по логу кодом, а не отметками руками, — правило granicu-proveryaet-kod про то же.

Следствие для ревизий: пока это не починено, отвечать на «что не применялось» честной фразой «счётчика нет», а не пустым списком. Пустой список читается как «всё в порядке» и врёт.
