# Черновики ответов живым людям

Здесь лежит текст, который показан Илье в ВК и ждёт его «да», «нет» или правки
(правило `ot-imeni-ili-cherez-chernovik`). Имя файла — `ГГГГ-ММ-ДД-кому.txt`.

Это не производное: пока Илья не ответил, файл — единственное место, где текст
живёт целиком. Отправленный черновик удаляется, факт отправки остаётся в
`../sent.jsonl`. Владелец — агент.
