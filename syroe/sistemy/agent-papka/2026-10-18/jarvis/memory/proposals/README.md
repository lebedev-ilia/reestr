Предложения агента, ждущие решения Ильи. Владелец — агент, решает Илья.

Статус в шапке файла — единственный признак того, ждёт ли предложение ответа:

- `proposed` — ждёт Илью. У каждого такого должно быть открытое обязательство
  в `memory/obligations.md`, иначе предложение забудется молча: обязательства
  перечитываются каждый цикл, а этот каталог — нет.
- `accepted` — решение принято, реализация переехала в ядро
  (CONSTITUTION.md / MEMORY.md / код). Файл остаётся как история: по нему
  видно, из чего выбирали и почему. Под сегодняшнее состояние он не
  переписывается — для «как оно устроено сейчас» есть факты.
- `rejected` — отклонено, остаётся с причиной отказа.

Меняя статус на accepted или rejected, впиши сразу под шапкой врезку: дата
решения, какое обязательство закрыто, и где решение живёт теперь (файлы,
правила, факты). Без неё через месяц непонятно, сделано это или забыто.
