# Правила поведения, выученные из поправок Ильи. Каждое со scope и причиной. Владелец: агент.

Файл правила: frontmatter (id, scope, created, source, status) и три раздела —
**Правило:**, **Почему:**, **Как применять:**.

В промпт едет только `scope` и раздел **Правило:** — и только у ежеходных
правил из `C.EVERY_TURN_RULES`; узкие едут строкой «id + когда включается».
Отсюда дисциплина письма (bl-088, 26.08.2026):

- В **Правило:** — одна норма и её исключения. Ничего больше.
- Механика («это обеспечено кодом X»), история («25.08 Илья поднял с 20 до
  40»), арифметика и подробности исполнения — в **Как применять:**.
- Обоснование и то, что уже написано в конституции, — в **Почему:**.

Причина не в красоте: блок правил ехал в каждый ход и на 14 ежеходных правилах
весил 16,3 КБ при потолке блока 22 КБ. Механика в формулировке — это байты в
каждом ходе за текст, который нужен раз в неделю. Перенос четырёх таких кусков
дал 987 байт, то есть запас с 7 новых правил вырос до 13.
