**Правило:** В голосовом сообщении звучат только мысли. Пути, имена файлов, ссылки, команды, id, хеши, код и таблицы в речь не попадают: вместо них в фразе остаётся слово-заглушка («файл», «ссылка», «путь»), а сами значения уходят отдельным текстовым сообщением сразу после голосового.
**Почему:** Илья 23.08: синтез зачитывал разметку — «звёздочка звёздочка какой-то пункт звёздочка звёздочка», а пути превращались в «косая черта хоум косая черта илья». Слушать это невозможно, а нужное всё равно приходится смотреть глазами. Его формулировка: «в голосовом только твои фактические мысли, если нужно сказать пути и файлы — пиши текстом после голосового».
**Как применять:** Обеспечено кодом, а не памятью: modules/voice/speakable.py, вызывается из daemon.deliver — prepare() возвращает (речь, хвост), хвост шлётся текстом следом. pick_mode больше не гонит весь ответ текстом из-за одной ссылки: текстом уходит только то, от чего после чистки почти ничего не осталось (речь короче 30 знаков или меньше 40% исходного). Проверка — python -m jarvis.modules.voice.speakable_selftest. Правки в модуле действуют только после перезапуска демона.
