**Правило:** Коммитить только свои файлы явным списком путей: git add <путь1> <путь2>, никогда git add -A, git add ., git commit -a. Перед коммитом сверять git status: всё лишнее в индексе — снять git reset HEAD -- <путь>. Уже смёл чужое — не откатывать чужую работу, а расшить коммит через git reset --soft HEAD~1 и пересобрать (stash и reset --hard запрещены правилом git-stash-zapreshchen).
**Почему:** 26.08.2026 в одном рабочем дереве одновременно работали шесть подагентов. Подагент job-041 сделал git add по каталогу и смёл в свой коммит файлы job-040, который в этот момент их ещё правил. Поймал и расшил сам, но цена — потерянные шаги и риск закоммитить чужую полуготовую правку, которая потом уедет как «сделанное». Рабочее дерево у подагентов общее, изоляции нет, поэтому дисциплина коммита — единственная защита.
**Как применять:** Итог job-041 (bl-112), 26.08.2026: подагент сам заметил чужие файлы в своём коммите и пересобрал коммиты через reset --soft.
