**Правило:** Задание подагента, оборванное по потолку шагов, оставляет в memory/jobs/<id>/result.md только служебную заглушку «ход упёрся в потолок» — реального итога там нет. Принимая такое задание, итог собирать из следов работы: memory/core_changes.md (если правилось ядро), git log/git show последнего коммита, файлы, которые задание должно было записать. Докладывать Илье по этим следам, а не по пустому result.md, и отдельно называть, что осталось недоделанным и каким продолжением закрыто.
**Почему:** 01.09 job-175 закрыл три дыры шлюза, закоммитил и прошёл живую проверку 15/15, но оборвался на оформлении: result.md остался заглушкой. По нему задание выглядит как «ничего не сделано» — доклад Илье был бы ложным, а работа могла уйти на повтор.
**Как применять:** Порядок: 1) открыть result.md; 2) если это заглушка про потолок — git log --oneline -5 и tail memory/core_changes.md, найти коммит задания; 3) прочитать раздел «Проверено» и «Риск» из журнала правок; 4) сверить, поставлено ли продолжение (job_continued в логе), и назвать его Илье одной строкой.
