# Модули

То, что агент написал себе сам. Ядро при этом не трогается.

Контракт: одна папка — один модуль, внутри `tool.py` с двумя объектами:

```python
SCHEMAS = [{"name": "...", "description": "...", "input_schema": {...}}]
IMPL = {"...": lambda **kw: {"результат": ...}}
```

Инструмент — чистая функция: аргументы на входе, словарь на выходе, никакого
состояния между вызовами. Всё, что нужно запомнить, идёт в общую память через
`remember_*`, а не в переменные модуля.

Ошибка возвращается как `{"error": "..."}` — не исключением. Провалы попадают
в лог и в статистику, и это намеренно: испорченная статистика полезнее красивой.

У каждого модуля свой README: зачем он, кто владелец, когда добавлен.
Не вызывался 30 дней — кандидат на удаление при месячной ревизии.
