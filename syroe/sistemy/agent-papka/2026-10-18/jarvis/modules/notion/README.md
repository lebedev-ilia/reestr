# modules/notion

Работа с воркспейсом Notion Ильи. Владелец: агент.

- `api.py` — чтение: search, базы, блоки, разбор свойств в текст
- `dump.py` — полный обход всего, что видно интеграции, в `derived/notion/`
- `write.py` — запись: архивирование, имена записей, правка текста блоков

Запись разрешена Ильёй 23.08.2026. Правила модуля записи:
ничего не удаляется навсегда (только архив = корзина Notion),
каждая правка сначала попадает строкой в `memory/notion_writes.jsonl`
вместе с состоянием «как было», и на всё есть `write.rollback()`.

Известное ограничение API: страницу верхнего уровня (родитель — workspace)
заархивировать нельзя, Notion отвечает 400. Такие — только руками Ильи.
