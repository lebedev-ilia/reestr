# memory/agents

Постоянные агенты-специалисты: по каталогу на роль. Здесь живёт то, что роль
накопила сама, — знания, журнал, уроки, состояние. Пересоздать это ничем нельзя,
поэтому каталог в memory/, а не в derived/.

Владелец каталога — главный агент. Внутри каждой роли владелец её содержимого —
сама роль: чужую папку роль не трогает, это проверяется при запуске.

Роль поднимается через `modules/agents/cli.py` поверх обычного диспетчера
заданий (`core/jobs.py`). Устройство и что взято из TrendFlowML/automation —
в `modules/agents/roles.py` и в факте `agents-postoyannye-roli`.
