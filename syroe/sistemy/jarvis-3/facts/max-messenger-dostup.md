Исследование 24.08.2026 по просьбе Ильи (нужен доступ агента к его аккаунту MAX). Итог: полного аналога канала ВК не получится, и причина устойчивая — пользовательского токена у MAX нет в принципе.

ПУТЬ 1. ОФИЦИАЛЬНЫЙ BOT API — легален, но это ОТДЕЛЬНЫЙ аккаунт-бот, а не аккаунт Ильи. Бот видит только чаты, где сам состоит; личную переписку Ильи не читает физически. Рабочая схема: Илья пишет своему боту, агент отвечает. База platform-api2.max.ru, токен в заголовке Authorization (в query-параметрах отключён), 30 rps, long polling GET /updates (официально «не для продакшена») либо webhook — с 25.05.2026 только HTTPS/443 с сертификатом доверенного УЦ. Вложения: image, video, audio, file, sticker, contact, inline_keyboard, share, location. ГОЛОСОВОГО ПУЗЫРЯ НЕТ: только audio (mp3/wav/m4a, до 256 МБ), уйдёт аудиофайл. Расшифровку входящих голосовых API не отдаёт вовсе — только своим STT.
БЛОКЕР ПУТИ 1: физлицо бота создать не может. Дословно help.max.ru: «Если вы являетесь физическим лицом, то создать собственного чат-бота в MAX не получится». Нужен статус самозанятого/ИП/юрлица и верификация на business.max.ru (через Госуслуги — минуты, по документам — до 4 рабочих дней). Один верифицированный аккаунт — до 5 ботов. Живые библиотеки: love-apples/maxapi, K1rL3s/maxo. Официальная max-messenger/max-botapi-python ЗАБРОШЕНА (пуш 30.07.2025) — не брать.

ПУТЬ 2. ЮЗЕРБОТ на внутреннем API — технически умеет всё, включая настоящие голосовые, но запрещён соглашением. Библиотека MaxApiTeam/PyMax (PyPI maxapi-python, MIT, живая): авторизация по номеру и SMS либо по QR веб-клиента, сессия в SQLite, приём, ответ, история, чаты, контакты. Голосовые — класс Voice, ТОЛЬКО готовый OGG, перекодирования нет (переименовать mp3 в .ogg не поможет, грузятся исходные байты). Есть VideoNote.
ЗАПРЕТ ПРЯМОЙ: соглашение legal.max.ru/ps, п. 4.3.7 (нельзя автоматизированные скрипты, боты, краулеры без разрешения компании) и п. 4.3.10 (нельзя использовать сервис иначе как через предоставленный интерфейс). Исключения для юзерботов нигде нет. П. 10.1.2 — доступ прекращается без уведомления.
ЦЕНА БАНА В MAX ВЫШЕ, ЧЕМ В ВК: аккаунт привязан к номеру и Госуслугам, мессенджер национальный. Потеря — это потеря канала к госсервисам, восстановление трудное.
Лимиты, за которыми банят: история чата 1 запрос/сек и максимум 5000 сообщений за 3 месяца, сообщения и файлы не более 50/сек, текст до 4000 знаков. Проверка базы контактов — блокировка на две недели.

ПУТЬ 3. Green-API — платный шлюз поверх того же юзербота: те же риски плюс передача учётных данных третьему лицу (запрещено п. 6.2.5). Голосовых нет. Не рекомендуется.

ЧТО ИЗ ЭТОГО СЛЕДУЕТ. Вопрос «нужен ли MAX» сводится к одному: агент читает личные переписки Ильи (только путь 2, с нарушением и риском аккаунта) или Илья разговаривает с агентом через MAX (путь 1, легально, но требует самозанятости и не умеет голосовые пузыри).

Не проверено: может ли бот писать пользователю первым без входящего /start (POST /messages принимает user_id, но предусловие не оговорено); цена тарифа Green-API именно для MAX.
